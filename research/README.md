## IMPORTANT — research environment limitation (read before using these files)

This research was produced inside a cloud session whose **network egress
policy blocked direct page retrieval**. Every attempt to fetch a source page
directly returned `EGRESS_BLOCKED`, including:

- `en.wikipedia.org`
- `lib.lsu.edu` (LSU Special Collections finding aid, Mss. 4698)
- `www.upi.com` (UPI archive articles)
- `www.courtlistener.com` (court opinions)
- `law.justia.com`
- `www.courts.michigan.gov` (the Michigan Court of Appeals opinion PDF)
- `dnadoeproject.org`
- `www.youtube.com`
- `apnews.com`, `www.nytimes.com`

**Web search was available and was used extensively.** Search returns page
titles, URLs and substantive extracted text, so the factual content below is
sourced — but it was verified at **search-extract level, not by reading the
source page end-to-end**.

Consequences for downstream production agents:

1. Per the brief's constraint #19, this limitation is recorded rather than
   papered over. Confidence ratings in each package already account for it.
2. Any claim marked **VERIFY BEFORE BROADCAST** must be confirmed against the
   primary document before it is narrated.
3. The court opinions cited (Hattori v. Peairs, People v Clay) are named with
   full citations and docket numbers so they can be pulled directly from a
   machine with unrestricted network access.
4. **All YouTube view counts, runtimes and publication dates are UNVERIFIED.**
   YouTube was unreachable, so `demand-research.md` records titles and URLs
   only and explicitly marks metrics as not observed. Do not assert view
   counts from these files. Do not describe any video as "viral".
5. No image file was downloaded. `visual-research.md` catalogues source pages
   and rights posture only.

Observation / access date for every web source in this batch: **2026-09-30**.
